# counter

Минимальное мобильное приложение-счётчик на React Native и Expo.

## Запуск

```bash
npm install
npm start
```

Открой приложение в Expo Go на телефоне (отсканируй QR-код) или в эмуляторе (Android/iOS).

## Экран

- Крупный текст с текущим числом по центру (начальное значение 0)
- Кнопка **+** — увеличивает значение на 1
- Кнопка **Сброс** — обнуляет счётчик
